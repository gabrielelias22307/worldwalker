Click any dot to see its episode card. This student is mid-year: Units 1–2 done, Unit 3 open.

WHAT THE STUDENT SEES

The whole world as one pixel map, split into 8 realms (one per unit). Each realm has 3 dots, one per episode, so 24 in all. Gold stamps show finished pages of the atlas. Realms still under purple fog are places the Smudge has blurred.

WHAT THEY LEARN HERE

  • Where each world region sits compared with the others
  • How the year's units fit together as one trip
  • Which of the five themes each episode builds

HOW IT PLAYS

Zelda-style gates: each realm needs the item from the realm before it. The Canoe from the Americas opens Europe; the Rail Pass from Unit 3 opens Africa, and so on. A teacher code can open any realm for a student who joins late.

Link to Canvas: each dot matches one Canvas module item. The same map is in every episode file. Pressing "Start episode" on a dot that belongs to a different file says "Open it from your Canvas module" (or opens that Canvas page in a new tab), so Canvas stays the place where work is turned in.
